# UI audit

This preserves the Web Interface Guidelines review mode formerly discovered as `web-design-guidelines` (upstream metadata author: vercel, version 1.0.0). Use only for a requested or concretely needed UI audit.

Fetch the current official rules from https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md through the host-approved browser or source-reading route. Follow the available host tools rather than assuming a `WebFetch` tool exists. If the source cannot be read, disclose that gap and distinguish any review against an older snapshot. Do not claim current compliance without current rules.

Read the requested files or pattern. If no target can be inferred from the request and project, ask for the target. Apply the fetched rules and their findings format; include concrete file and line locations, preferably the specified `file:line` format. Preserve security, accessibility and project checks while respecting the requested design.
