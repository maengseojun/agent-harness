작업 요청이 머지되기까지

요청은 세션에서 검증과 리뷰를 거쳐야만 머지돼요. 리뷰가 실패하면 세션으로 되돌아가고, 머지는 리뷰가 남긴 영수증을 확인한 뒤에만 열려요.

  • 주 경로
  • 데이터 읽기·쓰기
  • 일반 호출
  • 되돌림

  1. 세션: 요청을 받아 Spec과 Plan을 쓰고 Linear에 바인딩한다.
  2. 검증 게이트: Plan이 지정한 검사를 마지막 수정 뒤에 다시 돌린다.
  3. 리뷰: 정확한 head에 대한 리뷰를 받고 영수증을 남긴다.
  4. 머지: 영수증이 head와 맞을 때만 머지한다.

리뷰가 실패하면 리뷰에서 세션으로 되돌아가요. 리뷰 영수증은 리뷰와 머지를 잇는 유일한 연결이라, 영수증 없이 머지로 가는 경로는 없어요.
