# 글쓰기 브리프 (복사해서 채우기)

비워 둔 칸은 Claude가 한 번에 모아서 물어본다. 내 입장과 경험 칸은 Claude가 대신 채우지 않는다.

```markdown
## 과제 조건 (원문 그대로 붙여넣기)
- 

## 대상 자료
- 책/글/사건:
- 첨부한 분석·요약 자료:

## 내 메모
- 내 입장 (한 문장):
- 실제 경험 1: 무슨 일이 있었고 → 결과는 → 그래서 어떻게 생각하게 됐는지
- 실제 경험 2 (선택):
- 동의하지 않거나 판단을 미루는 부분과 그 이유:
- 앞으로에 대한 전망 (내 예상):
- 독자가 가져가야 할 것:

## 구성
1. 
2. 
3. 

## 형식
- 분량: (예: A4 2쪽 내외)
- 글자 크기 / 정렬: (예: 11pt, 양쪽 정렬)
- 제목 칸, 학번·이름 줄 위치:
- 파일 형식: (예: docx)
- 누구에게 하는 이야기인지: (예: 채점자, 같은 수업 학생들, 팀)
- 마무리 방식: 결론 / 제언 / 가설·열린 질문 / 아쉬운 점 / 성찰 중 하나
```
