# Applying writing and artifact tools

Read this when selecting, comparing or replacing a writing, report or presentation path. These decisions come from the bounded personal trial of 2026-10-10; they are starting criteria, not product benchmarks or a guarantee for every input. Recheck the actual version and prerequisites before running a candidate. Use official sources and verify license, execution path and any external API before installation or transmission.

## Choose by the missing capability

| Need | Default and candidate condition |
| --- | --- |
| Connected explanation | Use coherent-writing first. Humanizer may help remove concrete rhetorical excess after reasoning is settled. Keep the edited meaning and uncertainty intact; do not install a duplicate editor merely because it exists. |
| Evidence-heavy prose | Keep consequential claims linked to actual source passages and retain numerical conditions. Scientific-writing guidance may help an academic submission. A requirement for named human verification cannot be satisfied by an agent reading the source. |
| Editable Word report | Use the installed document path. OfficeCLI is an optional partial-edit route when it fits the task. Its tested edit preserved semantic content and formatting but rewrote XML, so do not promise byte preservation or universal roundtrip fidelity. |
| Editable presentation | Use the installed native presentation path. PPT Master is a candidate for SVG-first production or template work. The trial's native table/chart generation and data edit worked, with postflight warnings. Directly authored SVG does not demonstrate automatic writing or design superiority. |
| Web sharing | Use a self-contained HTML artifact when that satisfies the brief. Distinguish a fixed speaking deck from a mobile reading companion. Verify keyboard navigation, links, all screens and offline assets when offline use is required. A web deck is not a native PPTX. |

Keep spoken explanation and source notes when transferring to another format. Do not omit attribution just because a candidate's quick export disables notes. For diagrams, identify the relation the reader needs to understand first; use prose or a table if a diagram adds no explanatory value. Existing diagram guidance handles the actual figure when one is needed.

## Compare the actual operation

Use the same consequential text, figures and source links in both paths. For a partial edit, retain a before-copy and verify both the requested change and unaffected material. Compare semantic content and formatting separately from byte identity. For an editable chart, compare its visible values with its stored data/workbook and check that unrelated pages or slides are preserved.

Inspect the final revision in the requested renderer or target application. Repair actual defects and repeat only the checks affected by the repair. Korean fonts can render in a headless converter yet fall back through Office theme references; check the final title, body and table fonts and pagination. Chart labels can be much smaller than body text even when geometry checks pass.

Record the chosen path, demonstrated operation, warnings and unresolved requirements. Separate file creation, preservation, rendering and reader understanding. If the installed path meets the brief and the candidate adds no demonstrated benefit, keep the installed path. Do not stop the deliverable at this selection decision.
