## Selection examples

- "Build a Swiss-style monochrome website": consider frontend-guidance;
  retain the supplied style and read new-work only if direction is unresolved.
- "Build a dithered landing page with moving artwork": prefer
  the archived dither-motion-landing guidance from the MAE-127 GitHub archive;
  consult critique only for a separate hierarchy question.
- "Fix one button's padding": use existing tokens; no upstream fetch needed.
- "Audit accessibility": use the available audit skill; do not add a second
  stylistic review merely because both mention UI.
- "Make an HTML presentation": use frontend-slides; do not apply web-page
  responsive rules to its fixed slide canvas.

These are expected routing examples, not evidence of an actual generated page
or measured improvement. Evaluate usefulness on the next real design task.
